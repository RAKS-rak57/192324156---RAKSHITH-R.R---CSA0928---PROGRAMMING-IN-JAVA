=== Alternative design (Vehicle = interface, Chargeable = abstract class) ===
CarI fee(130) = 90.0, ElectricCarI fee(130) = 90.0, charge(10) = 120.0
Works, but: regNo is duplicated in every class, no constructor is shared, ElectricCarI is NOT a CarI,
and any class that needs Chargeable can no longer extend another class. See negative/ for the compiler errors.

time per call (ns): abstract-class method = 0.63, interface default method = 0.73 (sink=1)
Both are O(1) per call. Space per object: abstract class = 1 regNo field in the one superclass;
interface version = 1 regNo field in EACH implementing class (same bytes per object, but the field and constructor code are repeated).
