=== Which intrinsic lock does each form use? ===
  synchronized method      holds this lock         : true   holds class lock: false
  synchronized (this)      holds this lock         : true
  synchronized (private)   holds the private lock  : true   holds this lock: false
  static synchronized      holds the Class lock    : true
